# Shree_Travels

## Overview
The **Travel Agency System** is a web-based application developed using **Python (Django), HTML, CSS, and JavaScript**. It helps users browse travel packages, book tours, and manage travel-related activities efficiently.

## Features
- User Authentication (Sign up, Login, Logout)
- Browse and Search Travel Packages
- Book and Manage Trips
- Payment Gateway Integration (Razorpay)
- Admin Panel for Managing Packages and Bookings
- Responsive UI for better user experience

## Technologies Used
- **Backend:** Python (Django Framework)
- **Frontend:** HTML, CSS, JavaScript
- **Database:** SQLite (default Django DB)
- **Payment Gateway:** Razorpay

## Installation

### Prerequisites
Make sure you have the following installed:
- Python (3.x)
- pip (Python package manager)
- Virtual Environment (optional but recommended)

### Steps to Setup the Project
1. **Clone the Repository**
   ```sh
   git clone https://github.com/priynsh028/Travel_Agency_System.git
   cd Travel_Agency_System
   ```

2. **Create and Activate a Virtual Environment** (Optional but Recommended)
   ```sh
   python -m venv env
   source env/bin/activate  # On Windows use: env\Scripts\activate
   ```

3. **Install Dependencies**
   ```sh
   pip install -r requirements.txt
   ```

4. **Apply Migrations and Run the Server**
   ```sh
   python manage.py migrate
   python manage.py runserver
   ```

5. Open your browser and visit **http://127.0.0.1:8000/** to access the application.

## Usage
1. Register/Login as a user.
2. Browse available travel packages.
3. Select and book your desired trip.
4. Complete the payment using Razorpay.
5. Admins can manage bookings and travel packages from the admin panel.
